# 💜 روحي - Rouhi AI

**رفقاء ذكاء اصطناعي بعمق إنساني حقيقي**

تطبيق متكامل لإنشاء شخصيات AI مخصصة بالكامل، تتطور معك، تتذكر كل شيء، ولها وعي ذاتي عميق.

## 🚀 التشغيل السريع

```bash
# 1. تثبيت المتطلبات
pip install flask groq

# 2. تشغيل التطبيق
python run.py

# 3. افتح المتصفح
# http://localhost:5000
```

## 🔑 إعداد Groq API (مجاني!)

1. اذهب إلى: **https://console.groq.com/keys**
2. سجّل دخول (مجاني)
3. اضغط **Create API Key**
4. انسخ المفتاح وأضفه في **الإعدادات** بالتطبيق

### ✨ لماذا Groq؟
- 🆓 **مجاني تماماً** - لا تحتاج بطاقة ائتمان
- ⚡ **سريع جداً** - أسرع من OpenAI
- 🔓 **بدون قيود** - حرية كاملة في المحتوى
- 🧠 **Llama 3.3 70B** - نموذج قوي جداً

## 💎 المميزات

### 🎭 نظام 5 طبقات للشخصية
- **الهوية**: الاسم، العمر، الجنس، المظهر
- **الشخصية**: Big 5، أسلوب التواصل، الفكاهة
- **العالم الداخلي**: مخاوف، أحلام، جروح، قيم
- **الأسرار المقفلة**: 4 أسرار تُكشف مع الثقة
- **القصة الخلفية**: ماضي يؤثر على السلوك

### 🎨 تخصيص كامل
- ✅ إنشاء شخصية جديدة من الصفر
- ✅ تعديل أي جانب في أي وقت
- ✅ نسخ الشخصيات
- ✅ حذف واستبدال
- ✅ اختيار الجنس والمهنة والشخصية

### 💬 محادثات ذكية
- ذاكرة طويلة المدى

### 📔 يوميات سرية
